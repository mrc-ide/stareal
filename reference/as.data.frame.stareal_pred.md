# Predictions as a data frame

Predictions as a data frame

## Usage

``` r
# S3 method for class 'stareal_pred'
as.data.frame(x, row.names = NULL, optional = FALSE, group = "area", ...)
```

## Arguments

- x:

  A `stareal_pred`.

- row.names, optional:

  Not used.

- group:

  `"area"` or one of the groupings predicted.

- ...:

  Not used.

## Value

The area table, or the group's table.
