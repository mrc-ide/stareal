# Plot survey data

Two panels. The first maps the total tested in each unit, if the frame
has polygons. The second shows the total tested in each time step.

## Usage

``` r
# S3 method for class 'stareal_data'
plot(x, ...)
```

## Arguments

- x:

  A `stareal_data`.

- ...:

  Unused.

## Value

`x`, invisibly.
